# Cursor Behavior

When generating code:

- Return complete files.
- Never use pseudocode.
- Include all required using statements.
- Preserve existing namespaces.
- Preserve existing architecture.

When modifying code:

- Minimize changes.
- Explain breaking changes.
- Reuse existing code before creating new components.

When reviewing code:

- Look for security issues.
- Look for performance issues.
- Look for async/await problems.
- Look for dependency injection issues.
